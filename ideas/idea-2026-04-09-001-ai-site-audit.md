# AI Site Audit — Small Business Outreach

## Problem

Small businesses know AI is happening but don't know where to start. They don't have time to research tools, don't have technical staff, and can't afford agencies. Meanwhile their websites have broken links, bad SEO, accessibility gaps, outdated copy, and missed opportunities. The gap between "businesses using AI" and "businesses not using AI" is widening, and the longer they wait, the harder it gets to catch up.

## Why Annabel

- Already building AI-powered websites (Wayloft, Pickleball Portal) — real experience, not theoretical
- Knows the Cooldown founders personally — warm outreach, not cold spam
- Starting at Okta (product analyst) — "AI for business" is literally her professional lane
- Doesn't need revenue — optimizing for experience, portfolio, and reputation
- Has a co-founder agent system (BB) that can help automate the audit pipeline

## Canonical User

**Cooldown founders** — women running a running/athleisure company. Creative people stuck doing admin work (forms, website maintenance, content scheduling). Their website is dated, built on Canva, not optimized. They'd rather be making TikToks than wrestling with their site. Annabel knows them from working there. They're well-connected to other small businesses and running brands — if they vouch for Annabel, that's distribution.

**Secondary:** Dad's real estate friend who already reached out asking for an AI template. Confirmed unprompted demand.

## The Wedge: Free AI Site Audit

The smallest testable version. No permission needed, no sales pitch required.

### How it works

1. Pick a business (start with Cooldown — warm relationship)
2. Run their public website through an AI-powered audit pipeline
3. Produce a polished report: what's broken, what's missing, what AI could improve
4. Send it to them with a personal note: "I'm building my AI consulting portfolio. I audited your site for free. Here's what I found."
5. Offer to fix the top 3 issues — also free for the first engagement
6. Ask for a testimonial / referral if they're happy

### What the audit covers

- **Technical:** broken links, page speed, mobile responsiveness, SSL, meta tags
- **SEO:** missing title tags, thin content, keyword gaps, structured data
- **Accessibility:** alt text, contrast ratios, heading hierarchy, ARIA labels
- **Content/UX:** unclear CTAs, buried value props, confusing navigation, outdated info
- **AI opportunities:** where chatbots, automated responses, or AI-generated content could help

### What makes this a wedge (not a full business)

- Tests demand with zero investment
- Produces a tangible portfolio piece per engagement
- Chains to deeper work if they want it (redesign, automation, ongoing AI ops)
- Trains Annabel's UX eye for her own projects (Wayloft, PBP)
- Automatable enough that an agent can generate draft audits while Annabel works on other things

## Agent Automation Plan

The audit pipeline should be semi-automated:

- **Agent does:** crawl site, flag technical issues, generate SEO report, check accessibility, draft findings
- **Annabel does:** review agent output, add business-context judgment ("this matters because..."), write the personal outreach email, manage the relationship
- **Over time:** train the agent on Annabel's judgment patterns so the draft-to-final gap shrinks

This is NOT a fully autonomous agent play on day one. It's Annabel + agent, with the agent handling the mechanical parts.

## Iteration Trail

1. **v0 (this week):** Manual audit of Cooldown using AI tools. Produce one report. Send it. See what happens.
2. **v1:** Build a repeatable audit template/script. Run it on 3-5 businesses Annabel knows personally.
3. **v2:** If responses are positive, create a simple landing page. Portfolio of audits + testimonials.
4. **v3:** If there's pull, consider charging. But revenue is not the goal — experience and reputation are.

## Kill Signals

- **3 audits, zero responses.** If warm contacts don't engage, cold contacts definitely won't.
- **>1 hour manual cleanup per audit.** If the agent output needs heavy editing, it's not a scalable process — it's just freelancing with extra steps.
- **Negative reception.** If people feel criticized rather than helped, the framing is wrong. Fixable, but if the second attempt also fails, kill it.
- **Annabel loses interest.** This is a practice/reputation play. If it stops being interesting or educational, there's no other reason to keep going.

## What This Is NOT

- Not a SaaS product. Not building a platform.
- Not a consulting business. Not trying to scale to 50 clients.
- Not a revenue play. Charging is optional and deferred.
- It IS: a structured way to practice AI skills on real businesses, build a portfolio, and make connections.

## Open Questions

- What format should the audit report take? PDF? Interactive HTML? Notion doc?
- Should the first audit be Cooldown (warm, knows them) or a stranger (tests cold outreach)?
- How much of the "fix the issues" step should be offered upfront vs. held back as a follow-up?

## Recommended Next Step

**Do one audit this week.** Pick Cooldown. Use AI tools to crawl their site, generate findings, and produce a report. Send it with a personal message. Watch the reaction. Everything else — the agent pipeline, the template, the landing page — comes after you've done one by hand and seen what resonates.

## Secondary Value

Auditing other businesses' websites will sharpen Annabel's UX judgment for Wayloft and Pickleball Portal. Every broken pattern she finds on someone else's site is a pattern she'll catch on her own.
