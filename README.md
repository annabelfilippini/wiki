# Knowledge

This is the live Obsidian/Git knowledge vault.

Use `raw/` as the main intake folder for notes, articles, videos, transcripts, and clippings. Keep using the existing processed folders only when a workflow already depends on them.

Compatibility note: `../wiki` is a symlink to this folder, so older scripts and notes that reference `AI-OS/wiki/...` should still resolve while references are migrated to `AI-OS/knowledge/...`.
