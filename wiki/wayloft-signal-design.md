# Signal Design System

## Key Takeaways
- Direction: "The Signal" — data IS the interface. No decoration except what communicates.
- Mood: "Competent, precise, utilitarian. Like a Bloomberg terminal designed by Linear."
- Competitive differentiation: every competitor uses purple/blue SaaS aesthetics with generic sans-serif
- Dual-track system:
  - App track (authenticated): dark surfaces (Carbon #0F0F0F), tight spacing, monospace data
  - Content track (SEO/marketing): light surfaces (Warm White #FAFAF6), comfortable reading
- Both tracks share: Geist/Geist Mono typography, Amber accent, component patterns
- Default mode: Light. User toggle in settings. System preference disabled.
- Amber #D4A020 is the ONLY brand color. Connects to credit card premium positioning.
- Wordmark: WAYLOFT in Geist Mono 700, -0.04em tracking, Amber
- Spacing base: 4px. Border radius: sharp (0px default, max 2px). Cards get 8px.
- Navigation: top horizontal bar (desktop), bottom tab bar with 4 tabs (mobile). Sidebar removed.
- Motion: minimal-functional. No entrance animations, no scroll effects.
- Empty states: "data-shaped void" — show container as it would look with data, ghost placeholders
- Progressive activation: dashboard sections appear as data fills them
- Anti-patterns: purple gradients, 3-column grids with colored circles, bubbly radius, blobs/waves, emoji as design
