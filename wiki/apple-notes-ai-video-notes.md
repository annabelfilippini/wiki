# Apple Notes: AI Video Notes

## Key Takeaways
- Four powers framework: Build, Automate, Create, Connect
- Each power maps to specific tools and skills to develop
- Key tools per power: Bolt (build), Zapier/Make (automate), Midjourney/Suno (create), Claude (connect)
- API integration via Postman ties the automation layer together
