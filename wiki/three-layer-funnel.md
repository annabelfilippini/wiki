# Three-Layer Funnel

[[wayloft]]'s distribution strategy. Approved April 1, 2026 via /office-hours. The core problem: Wayloft is fully built and deployed but has **zero users**. The problem is distribution, not features.

## The Funnel

| Layer | What | Status | Key Dependency |
|-------|------|--------|----------------|
| 1 | [[ellis-church]] + SEO content (reviews, [[worth-it-tool]], best-of guides) | In progress | Persona design |
| 1.5 | Browser extension ("Which Card Right Now") | Deferred to post-checkpoint | MV3 constraints, 30s service worker timeout |
| 2 | Personalized newsletter via [[beehiiv]] | Not started | Subscriber source unclear |
| 3 | Full portfolio app | Already built | None — no changes needed |

## The Assignment

"No new backend features for the next 4 weeks. Everything you build should be content, distribution, or extracting existing features into public-facing tools."

## Key Strategic Decisions

- Transfer bonuses as the wedge is **wrong** — audience tiny, already served by Frequent Miler. AF decision helper is better entry point.
- [[worth-it-tool]] is the googleable wedge: "[card name] worth the annual fee" = high-intent, lower competition SEO
- Extension tension left unresolved — checkpoint data decides
- Checkpoint: if Worth-It <50 Reddit uses → pivot to content/SEO. If >50 → evaluate extension.
- No budget for paid acquisition — organic only
- Affiliate rejection contingency: Amazon Associates + Skimlinks as fallback

## Success Targets

| Timeframe | Newsletter | Web App | Extension | Revenue |
|-----------|-----------|---------|-----------|---------|
| 30 days | Signup live | Tool live for top 5 | MVP on Chrome Store | — |
| 90 days | 500 | 100 signups | 200+ installs | $50/mo |
| 6 months | 2,000 | 500 active | 1,000+ | $500/mo |
| 12 months | 10,000 | 2,000 active | 5,000+ | $2,000/mo |

## Risk

Demand evidence is thin. One named user (Annabel's dad). "You said 'honestly, just me' when asked about demand evidence." The funnel tests whether real demand exists before building more features.
