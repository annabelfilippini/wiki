# Apple Notes: Wayloft Notes

## Key Takeaways
- **Goal:** Ambient businesses (low-maintenance, compounding value)
- **UX bugs:** Perks/benefits checkboxes don't visually update after checking; card recommendation images have overlapping text
- "Cards to consider" links back to quiz when clicking "view full breakdown" -- confusing flow
- Quiz recommendations page: make it clearer users should click checkboxes to compare
- Earning velocity section should match spending optimizer theme
- "Where your points could go further" should show actual destination images (Istanbul, Canada, etc.)
- Gstack workflow advice: /plan-eng-review -> /ship -> /design-consultation -> /qa

## New Information
Active UX feedback for [[wayloft]]. The "ambient businesses" framing is a strategic goal. Updates [[worth-it-tool]] with specific UI issues.
