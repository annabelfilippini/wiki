I want to create an app that allows endurance athletes to be able to visually see the race course before the race begins. For example, often times athletes will go and “drive the course” before their race. I don’t want this to be necessary anymore. I want people to be able to open an app, put in the race they are participating in, select the mile they want to visually see and see the course all from their phone. For example, if an athlete was particularly nervous about miles 24-26 of their marathon they would be able to see the course across these 3 miles. 

I want this app to have an opening page where you select the race and miles, then the second screen you are able to see course strategies, expected weather, and suggested race plan for that part of the race. 

Additionally on the second screen I want an overall map with the section of miles highlighted that the user chose to deep dive in on. Below this map is the virtual video and below the virtual video is an elevation map that also follows the virtual map so runners are able to see where they are on the overall map, what the course will look like via video and then what the elevation will be.
